# Dehan's Cyberpunk Portfolio

A modern, visually stunning portfolio website showcasing my skills, projects, and professional experience with a cyberpunk aesthetic and glassmorphism design. Built with React and Vite, optimized for performance across all devices.

## 🌐 Live Demo

Check out the live portfolio at: [h4n.dev](https://h4n.dev)

## ✨ Features

- **Cyberpunk Design**: Futuristic visual theme with glassmorphism effects, neon accents, and dynamic backgrounds
- **Responsive Layout**: Fully responsive design that works on mobile, tablet, and desktop
- **Performance Optimized**: Optimized for mid-to-low end devices with efficient rendering
- **Dark/Light Theme**: Toggle between dark and light mode
- **Interactive Elements**: Smooth animations and hover effects powered by Framer Motion
- **3D Console Effects**: Dynamic floating console artifacts for a cyberpunk feel
- **Project Showcase**: Expandable project cards with detailed descriptions
- **Skill Visualization**: Interactive skill progress indicators with percentage ratings
- **Career Objectives**: Detailed career goals and vision sections

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: CSS Modules, Glassmorphism Effects
- **Animations**: Framer Motion
- **Fonts**: Orbitron (Google Fonts)
- **Build Tool**: Vite
- **Responsive Design**: CSS Grid & Flexbox

## 🎨 Design Elements

### Visual Theme
- **Dark Mode**: Primary theme with cyberpunk aesthetics
- **Glassmorphism**: Frosted glass effect cards with `backdrop-filter: blur()`
- **Neon Accents**: Gradient text and glow effects using CSS
- **Typography**: Orbitron font for futuristic feel

### Performance Optimizations
- React.memo for component optimization
- Efficient state management with hooks
- Lazy loading for images (optional)
- Optimized animations and transitions
- Font loading with `display=swap`

## 🏗️ Setup & Development

1. Clone the repository:
```bash
git clone <repository-url>
```

2. Install dependencies:
```bash
cd portfolio
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser to `http://localhost:5173`

## 📦 Deployment

The portfolio is optimized for deployment on platforms like:
- GitHub Pages
- Vercel
- Netlify
- Any static hosting service

To build for production:
```bash
npm run build
```

## 💡 Key Optimizations

1. **Component Optimization**: Used React.memo to prevent unnecessary re-renders
2. **Data Management**: Moved static data outside component to avoid recreation
3. **CSS Performance**: Optimized glassmorphism effects and animations
4. **Font Loading**: Used `display=swap` for non-blocking font loading
5. **Image Handling**: Optimized image loading strategies
6. **Memory Efficiency**: Proper state management and cleanup
